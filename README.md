# 🔀 Git

Практика работы с **Git-командами**:

- создание локального репозитория;
- клонирование;
- подключение удалённого репозитория;
- коммиты;
- отправка и получение изменений;
- работа с ветками;
- просмотр истории.

## Задача 1

##### Создание локального репозитория и публикация на GitHub
```bash
cd /d/qa                                                      # Перейти в папку, где хранятся локальные репозитории
mkdir example                                                 # Создать папку нового репозитория
cd example                                                    # Перейти в папку example
git init                                                      # Инициализировать локальный Git-репозиторий
touch README.md                                               # Создать файл README.md
git status                                                    # Проверить текущее состояние репозитория
git add .                                                     # Добавить все файлы из текущей папки в staging area
git commit -m "Initial commit"                                # Создать первый коммит с сообщением
git remote add origin https://github.com/qa-novchenkova/example.git   # Подключить удалённый репозиторий GitHub
git branch -M main                                            # Переименовать текущую ветку в main
git push -u origin main                                       # Отправить локальную ветку main в удалённый репозиторий и связать их
```

## Задача 2

##### Клонирование и базовая синхронизация с удалённым репозиторием
```bash
git clone https://github.com/qa-novchenkova/example.git       # Клонировать удалённый репозиторий на компьютер
cd example                                                    # Перейти в папку клонированного репозитория
git status                                                    # Проверить состояние локальной ветки
git pull                                                      # Получить и применить изменения из удалённого репозитория
git fetch                                                     # Получить информацию об изменениях без применения к локальным файлам
git log HEAD..origin/main --oneline                           # Посмотреть коммиты, которых нет в локальной ветке
git diff HEAD origin/main                                     # Сравнить локальную ветку с удалённой
git push                                                      # Отправить локальные коммиты в удалённый репозиторий
```

## Задача 3

##### Работа с изменениями и коммитами
```bash
git status                                                    # Показать новые, изменённые и отслеживаемые файлы
git add README.md                                             # Добавить конкретный файл в staging area
git add .                                                     # Добавить все изменения в staging area
git commit -m "Update README"                                 # Создать коммит с сообщением
git log --oneline                                             # Показать историю коммитов в сокращённом виде
git diff                                                      # Показать изменения, которые ещё не добавлены в staging area
git diff --staged                                             # Показать изменения, уже добавленные в staging area
git restore README.md                                         # Отменить локальные изменения в файле
git rm old_file.txt                                           # Удалить файл из репозитория и из рабочей папки
```

## Задача 4

##### Работа с ветками
```bash
git branch                                                    # Показать список локальных веток
git branch feature-readme                                     # Создать новую ветку feature-readme
git checkout feature-readme                                   # Переключиться на ветку feature-readme
git checkout main                                             # Вернуться на ветку main
git merge feature-readme                                      # Влить изменения из feature-readme в текущую ветку
git branch -d feature-readme                                  # Удалить ветку после слияния
```

## Использованные элементы команд

- `init` — инициализация нового локального Git-репозитория.
- `clone` — клонирование удалённого репозитория на локальный компьютер.
- `status` — просмотр текущего состояния репозитория.
- `add` — добавление файлов в staging area.
- `commit` — сохранение изменений в историю репозитория.
- `remote add` — подключение удалённого репозитория.
- `push` — отправка локальных коммитов в удалённый репозиторий.
- `pull` — получение и применение изменений из удалённого репозитория.
- `fetch` — получение информации об изменениях без автоматического применения.
- `branch` — работа с ветками.
- `checkout` — переключение между ветками.
- `merge` — слияние веток.
- `log` — просмотр истории коммитов.
- `diff` — просмотр различий между версиями файлов.
- `restore` — отмена локальных изменений.
- `rm` — удаление файла из репозитория.
- `staging area (индекс)` — область, где собираются изменения перед коммитом.

## Использованные флаги

- `-m` — передать сообщение коммита прямо в команде `git commit`.
- `-M` — принудительно переименовать ветку.
- `-u` — связать локальную ветку с удалённой (`--set-upstream`).
- `--oneline` — показать историю коммитов в сокращённом виде.
- `--staged` — показать изменения, уже добавленные в staging area.
- `-d` — удалить ветку после слияния.
